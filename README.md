# Команда MR dev

Мы — команда из двух разработчиков (бэкенд и фронтенд). Здесь собраны все наши проекты, сделанные в процессе обучения и для портфолио.

## Команда

- **Рамазан** — бэкенд (Python, Flask, SQL, деплой)
- **Магомед** — фронтенд (HTML, CSS, адаптивная вёрстка)

## Проекты

### 1. Сайт-портфолио (`/portfolio_site`)
- Наш первый совместный проект.
- Назначение: представить команду и хранить ссылки на другие проекты.
- Технологии: Flask, HTML, CSS.
- Статус: ✅ работает.

### 2. Сайт пекарни (`/bakery_site`)
- Динамический сайт-визитка для вымышленной пекарни.
- Особенности: каталог товаров, карточка товара, форма заказа, хранение данных в JSON.
- Технологии: Flask, HTML, CSS, JSON.
- Статус: ✅ работает.

### 3. Магазин техники (`/MR_Eco_Site`)
- Учебный интернет-магазин с БД.
- Особенности: каталог, карточка товара, форма заказа, база данных (SQLite / PostgreSQL), админка для товаров.
- Технологии: Flask, SQLAlchemy, HTML, CSS, SQLite/PostgreSQL.
- Статус: 🚧 в разработке.

## Общий стек

- **Бэкенд:** Python 3.10+, Flask, SQLAlchemy, Flask-Migrate
- **Базы данных:** SQLite (локально), PostgreSQL (на сервере)
- **Фронтенд:** HTML5, CSS3 (адаптивная вёрстка)
- **Инструменты:** Git, GitHub, Render (деплой)

## Как запустить любой проект локально

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/reg1n-021/team-portfolio.git
   cd team-portfolio/[название нужной папки для каждого сайта]

2. Создать виртуальное окружение и установить зависимости:
    python -m venv venv
      source venv/bin/activate  # Linux/Mac
    # или
    venv\Scripts\activate  # Windows
    pip install -r requirements.txt

3. Запустить
    python run.py
